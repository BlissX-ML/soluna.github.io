1. `box-sizing` 的三个取值
    - `content-box`：宽高只包含内容，不包含 padding 和 border（默认值，**标准盒模型**）。
    - `border-box`：宽高包含内容 + padding + border（**IE 盒模型**，更易布局）。
    - `inherit`：继承父元素的 box-sizing。
2. 一句话总结
    - content-box = 宽高只算内容；
    - border-box = 宽高把内边距和边框也算进去。
