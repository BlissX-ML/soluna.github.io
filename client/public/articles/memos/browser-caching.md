1. 浏览器缓存分为两类：**强缓存** 和 **协商缓存**。
2. **强缓存**
    - 不会发请求。状态码不是 304，是压根没有请求。
    - 控制字段：`Expires`、`Cache-Control`。
    - 优点：速度快，不占用网络。
    - 如果缓存过期，才会进入协商缓存流程。
3. **协商缓存（304 Not Modified）**
    - 浏览器会向服务器发送请求，带上缓存标识：
        - `If-Modified-Since`（配合 `Last-Modified`），根据时间判断是否过期
        - 或 `If-None-Match`（配合 `ETag`），根据唯一标识判断是否过期
        - **需要服务端配合设置**，浏览器不会自己生成。
    - 服务器验证资源是否更新：
        - 如果资源没改 → 返回 **304**，浏览器用本地缓存。
        - 如果资源改了 → 返回 **200 + 新资源**。
4. **304 的调用流程**
    - 浏览器请求资源 → 携带 `If-Modified-Since` 或 `If-None-Match`。
    - 服务器检查：
        - 没有变化 → 返回 **304 Not Modified**，不传资源内容。
        - 已更新 → 返回 **200 OK** 并带新资源。
5. **200 (from cache)** → 其实是强缓存，表示浏览器直接用本地的。
6. **304** → 属于协商缓存，表示服务器确认没变，浏览器用本地的。
