1. **垃圾回收机制的核心概念**
    1. **GC 的作用**：自动释放**不再被使用**的对象所占的内存。
    2. 判断依据：对象是否还能被访问（是否仍被引用）。
2. **引用计数（早期算法，已淘汰）**
    1. 思路：对象被引用次数为 0 → 可回收
    2. 简单直接，但无法处理循环引用。循环引用 / 互相引用会导致引用计数无法归零
3. **标记清除（现代浏览器主流算法）**
    1. **思路**：从**根对象**开始递归标记**能访问到的对象**。
        - 可达则保留，不可达则回收
    2. **优点**：解决循环引用问题，是当前标准方案。
4. **引擎常见优化**
    - **分代回收**：新对象检查频繁，**老对象检查减少**，提高效率
    - **增量回收**：把大回收拆成**多次小回收**，减少一次性卡顿。
    - **闲时回收**：在 CPU **空闲时**运行 GC，尽量不影响程序执行。
