1. **检查缓存**
    - 浏览器先检查本地缓存（强缓存、协商缓存），命中则直接使用，否则继续网络请求。
2. **DNS 解析**
    - 将域名解析为 IP 地址，可能依次查询浏览器缓存、本地 hosts、DNS 服务器。
3. **建立 TCP 连接**
    - 浏览器与目标服务器通过 **三次握手** 建立可靠的 TCP 连接。
4. **发送 HTTP 请求**
    - 浏览器封装**请求报文**（请求行、请求头、请求体）并通过 TCP 发送。
5. **服务器处理并返回响应**
    - 服务器生成 HTTP **响应报文**（状态码、响应头、响应体），并将页面资源返回给浏览器。
6. **浏览器解析与渲染**
    - 解析 HTML 构建 **DOM 树**
    - 解析 CSS 构建 **CSSOM 树**
    - 执行 JS，可能修改 DOM/CSSOM
    - 结合 DOM + CSSOM 生成渲染树 → 布局（reflow） → 绘制（repaint）
7. **断开 TCP 连接**
    - 数据传输完成后，客户端和服务器通过 **四次挥手** 断开 TCP 连接。
8. **总结**：缓存检查 →  DNS 解析 → TCP 三次握手 → 发送 HTTP 请求 → 服务器返回响应 → 浏览器渲染页面 → TCP 四次挥手
