1. `opacity: 0`
    - 元素透明不可见，但**仍占据空间**。
    - 绑定的事件（如 `click`）仍然可以触发。
    - 只会触发 **重绘**。
2. **`visibility: hidden`**
    - 元素不可见，但**仍占据空间**。
    - 绑定的事件**不会触发 ❌**
    - 只会触发 **重绘**。
3. `display: none`
    - 元素彻底从文档流移除，**不占据空间 ❌**。
    - 事件**不会触发 ❌**
    - 触发 **回流 + 重绘**。

4. **隐藏元素方法的进一步扩展**

| 隐藏方式 | 是否占空间 | 是否触发事件 | 回流 / 重绘 |
| --- | --- | --- | --- |
| `opacity: 0` | ✅ 占空间 | ✅ 能触发事件 | **重绘** |
| `visibility: hidden` | ✅ 占空间 | ❌ 不能触发事件 | **重绘** |
| `display: none` | ❌ 不占空间 | ❌ 不能触发事件 | ✅ **回流 + 重绘** |
| `position: absolute; left:-9999px;` | ❌ 不占空间（相对视口看不到） | ✅ 能触发事件 | ✅ **回流**（位置变化） |
| `z-index: -1` | ✅ 占空间 | ❌（被挡住，一般点不到） | **重绘** |
| **`transform: scale(0)`** | ✅ 占空间 | ✅ 能触发事件（虽然看不见） | **合成层（GPU）** |
| `clip-path: circle(0)` | ✅ 占空间 | ✅ 能触发事件（裁剪区外无效） | **重绘** |
| `hidden` 属性 (`<div hidden>`) | ❌ 不占空间 | ❌ 不能触发事件 | ✅**回流 + 重绘** |

* `clip-path` 是 CSS 裁剪属性，用来定义元素可见区域
