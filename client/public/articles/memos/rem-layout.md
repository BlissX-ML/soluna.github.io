1. **原理**
    - `1rem` 相对于 **根元素 (html)** 的 `font-size`
    - 通过在根元素上动态设置 `font-size`，实现**页面整体的等比缩放**
    - 一般基于设备宽度动态设置 **`html { font-size }`**
2. **优点**
    - **移动端适配常用**，能保持图片、字体、盒子等的比例统一
    - **等比缩放**，便于响应不同屏幕宽度
    - 有 VSCode 插件 / PostCSS 插件（如 `px2rem`）辅助转换，减少人工计算成本
3. **缺点：**所有元素都需要精确换算成 rem，**数据量大**
4. **现状**
    - 现代浏览器已全面支持 rem，在移动端开发中仍然常用
    - PC 端多用 `em` / `%` / `vw/vh` 等替代
5. **面试速答：**
    
    REM 是一种相对长度单位，参照的是根元素 `<html>` 的 `font-size`。**好处**是可以方便地做响应式布局。缺点是需要把 px 转换成 rem，维护成本稍高。
