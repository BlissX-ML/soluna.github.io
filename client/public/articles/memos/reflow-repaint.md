1. **回流/重排（Reflow）**
    - **定义**：当 **DOM 的几何属性（尺寸、位置）或结构**变化时，浏览器需要**重新计算布局**。
    - **特点**：涉及到布局计算，会影响该元素和相关的父子元素，**性能开销大**。
    - **触发场景**：**新增/删除 DOM、改变元素大小、display 切换**等。
2. **重绘（Repaint）**
    - **定义**：当元素的 **样式外观** 发生变化，**但不影响布局**时，只需要重新绘制外观。
    - **特点**：只更新像素，不需要重新计算布局，**性能开销较小**。
    - **触发场景**：**color、background、visibility**、opacity 等变化。
3. **两者的关系：**回流一定导致重绘，重绘不一定导致回流
4. **为什么回流比重绘开销大？**
    - 回流要重新计算 **几何尺寸和布局**，可能会连锁影响很多节点。
    - 重绘只是在原有布局上重新填充像素，不涉及排版。
    - 一般认为：**回流 > 重绘 > 合成层变换（GPU 加速）**，性能开销逐级减少。
5. **如何减少重排/重绘**
    - **合并修改，**集中改变样式
    - **减少 DOM 访问**
    - **脱离文档流**：优先修改 `position: absolute/fixed` 元素，减少对其他元素的影响
    - **合成层优化**：使用 GPU 合成层，避免触发 layout 和 paint
        - 常见方法：`transform`、`opacity`、`will-change`
