1. **XSS（跨站脚本攻击）**
    - **原理**：恶意脚本被**注入页面**并在浏览器**执行**，可窃取 cookie、session 等敏感信息
    - **防御方式**：
        - URL 参数用 **`encodeURIComponent` 转义**
        - HttpOnly Cookie
        - 输入过滤
2. **CSRF（跨站请求伪造）**
    - **原理**：攻击者诱导用户在**已登录状态下**向可信网站发送恶意请求
    - **防御方式**：
        - 添加**验证码**
        - 使用 **token 验证**机制（服务端生成并校验）
3. **SQL 注入**
    - **原理**：在输入中注入**恶意 SQL 语句**，后台数据库执行后造成数据泄露或破坏
    - **防御方式**：
        - **参数化查询**（Prepared Statement）
        - 输入校验与过滤
4. **DDoS（分布式拒绝服务）**
    - **原理**：攻击者利用**大量请求造成资源过载**，使服务器无法正常服务
    - **防御方式**：
        - 限制单 IP 请求频率
        - 防火墙过滤异常流量（如禁止 ICMP 包）
        - 检查和关闭不必要的特权端口
5. **Web 攻击速记总结**
    - XSS（跨站脚本 → 注入恶意脚本） → 解决：转义输入 / 避免 innerHTML
    - CSRF（跨站请求伪造 → 第三方伪造请求） → 解决：验证码 / Token 校验
    - SQL 注入（恶意 SQL 拼接 → 操控数据库） → 解决：参数化查询 / 输入过滤
    - DDoS（分布式拒绝服务 → 大量请求超载） → 解决：限流 / 防火墙 / 关闭无用端口
