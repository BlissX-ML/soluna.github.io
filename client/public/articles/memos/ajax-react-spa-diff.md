---
titleEn: "The Difference Between AJAX and React SPA"
titleCh: "AJAX 与 React SPA 的区别"
tags: ["JavaScript"]
---


1. **AJAX**：
    - 一种**技术手段**，用于异步请求数据。
    - 基于 `XMLHttpRequest`/`Fetch` 实现异步数据请求，更新部分页面内容。
2. **SPA (单页应用)**：
    - 一种应用**架构模式**。
    - 通常用 React/Vue 实现，依赖路由管理和组件渲染。
    - SPA 内部的数据获取方式往往还是 AJAX/Fetch。
3. **区别**：AJAX 是技术，SPA 是架构。
4. **关系**：SPA 内部通常用 AJAX/Fetch 获取数据
