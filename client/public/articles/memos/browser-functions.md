1. **浏览器的主要功能（请求资源 → 渲染展示）**
    - 向服务器发出请求，在浏览器窗口中展示网络资源
    - 资源类型：HTML、PDF、图片等
    - 资源位置通过 **URI（统一资源标识符）** 指定
2. **浏览器的主要组成部分**
    - **用户界面：**地址栏、前进/后退按钮、书签菜单等
    - **浏览器引擎（协调模块）**
        - 协调**内部模块**
        - 本身不是一个独立“看得见的界面”，而是**协调模块**
    - **渲染引擎**
        - 显示请求的内容，解析 HTML、CSS 并渲染到屏幕
        - **画网页的模块**：解析HTML和CSS得到渲染树，布局位置大小再进行渲染
    - **网络模块**
        - 处理网络调用，如 HTTP 请求
        - 提供跨平台的底层实现
    - **UI 后端**：绘制基础控件（如字体、窗口元素）
    - **JavaScript 解释器：**解析并执行 JavaScript 代码
    - **数据存储：**浏览器持久化存储，如 Cookie、LocalStorage 等
