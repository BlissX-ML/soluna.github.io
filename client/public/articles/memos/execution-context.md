1. **执行上下文的核心概念**
    1. JS 代码运行时一定在**执行上下文**中进行。
    2. 类型只有三种：**全局上下文**、**函数上下文**、**eval 上下文**
    3. 每次进入一段新代码（如调用函数）都会创建一个新的上下文，并**压入执行上下文栈**
2. **执行上下文的两个阶段**
    1. **创建阶段（代码未执行前）**
        - **创建变量环境 / 词法环境**
        - **处理声明**：变量与函数声明被创建，变量初始化为 `undefined`（变量提升）
        - **确定 this 的指向**：全局 this → window；函数 this 视调用方式而定
        - **确定作用域执行阶段（代码真链**（用于变量查找）
    - **正运行时）**
        - **顺序执行**：按顺序执行代码
        - **变量赋值**
        - **结果**：函数被调用、返回结果
        - **销毁上下文**：执行完成后上下文被销毁，栈顶弹出
