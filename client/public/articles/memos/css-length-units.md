titleEn: "CSS Length Unit Comparison"
titleCh: "CSS 长度单位对比"
tags: ["CSS"]
---


1. **`px`**
    - 像素单位，**绝对长度**
    - 与屏幕像素点对应，常用但**不随环境缩放**
2. **`em`**
    - **相对单位**，相对于父元素的 font-size
    - **特殊**：在 font-size 属性中，em 相对父元素的字体大小
    - **特点**：**会继承**，容易层层放大/缩小
    - **示例**：父元素 `font-size: 16px`，则子元素 `width: 2em = 32px`
3. **`rem`**
    - **相对单位**，相对于根元素 (html) 的 font-size
    - 常用于**响应式布局**，避免 em 的多层级计算问题
    - **示例**：html 设置 `font-size: 10px`，则任意元素 `2rem = 20px`
4. **`vw / vh`**
    - **视口单位**
    - 1vw = 视口宽度的 1%，1vh = 视口高度的 1%
    - **示例**：浏览器宽度 `1200px → 50vw = 600px`
    - **优势**：vh 可以直接获取可视区域高度，而 % 必须父元素有高度
5. **`%`**
    - 相对父元素的百分比
    - 宽度：相对父元素宽度
    - 高度：必须父元素有明确高度才能生效
6. **`ex`**
    - 相对于字体的 x-height（小写字母 x 的高度）
    - 与 em 不同，会**随字体族 (font-family) 变化**
