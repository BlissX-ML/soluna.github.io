titleEn: "Variable Hoisting"
titleCh: "变量提升"
tags: ["JavaScript"]
---


1. **定义**
    - JavaScript 执行代码前的**创建阶段**，会将`var / function` 的声明提升到当前作用域的顶部
    - 因此它们可以在声明之前被访问，这个现象就叫 **变量提升（Hoisting）**。
2. **执行过程（两个阶段）**
    - **创建段**：扫描作用域 → 收集变量声明 → 收集函数声明（整体提升）
    - **执行阶段**：按顺序运行代码并给变量赋值
3. **不同声明的提升规则**
    - `var`：只提升声明，初始值为 `undefined`
    - `function`：函数整体被提升（可在定义前调用）
    - `let / const / class`：**不提升为可访问的变量**，进入块级作用域时处于 **TDZ（暂时性死区）**
4. **同名覆盖规则**
    - 同一作用域里，若 `var` 和 `function` 同名，**函数声明优先级更高**
    - 如果出现多个同名 function，**后出现的覆盖之前的**
    - **后定义者覆盖先定义者**
