1. **1xx 信息响应**（继续处理，临时响应）
    - **100 Continue**：继续请求（大文件分块上传常见）
    - **101 Switching Protocols**：协议切换（WebSocket 常见）
    - **归属**：正常提示，不算错误
2. **2xx 成功响应**（请求成功处理完成）
    - **200 OK**：请求成功
    - **201 Created**：已创建新资源（POST/PUT 成功）
    - **204 No Content**：请求成功但无返回内容（DELETE 常见）
    - **归属**：表示成功，不是错误
3. **3xx 重定向**（需要客户端进一步操作）
    - **301 Moved Permanently**：永久重定向（资源有新 URL）
    - **302 Found**：临时重定向
    - **304 Not Modified**：资源未修改，直接使用缓存
        - 条件：浏览器带 `If-Modified-Since` / `If-None-Match`，资源没变 → 返回 304
        - 好处：节省带宽、提升速度
    - **归属**：不是错误，属于跳转或缓存控制
4. **4xx 客户端错误**（客户端请求有问题）
    - **400 Bad Request**：请求**语法错误**
    - **401 Unauthorized**：未认证（缺少/错误的凭证，需要登录）
    - **403 Forbidden**：服务器理解请求，但拒绝执行
        - 场景：权限不足、IP 被封、目录禁止访问
    - **404 Not Found**：资源不存在
        - 场景：URL 错误、资源被删除或移动、路径配置错误
    - **逻辑思路**：请求问题 → 身份问题 → 权限问题 → 资源问题
    - **归属**：**前端/客户端问题**（URL 写错、没带认证信息、权限不足）
5. **5xx 服务器错误**（服务器端处理出错）
    - **500 Internal Server Error**：服务器内部错误（代码异常）
    - **501 Not Implemented**：服务器**不支持**请求的方法或功能（例如 `PATCH` 方法服务端不支持）
    - **502 Bad Gateway**：**网关收到无效响应**（下游服务挂掉）
    - **503 Service Unavailable**：网关能连上服务，但服务**超载/维护**，暂时不可用（**服务器不可用**）
    - **504 Gateway Timeout**：网关能连上服务，但服务迟迟不响应，**超时**（下游服务无响应）
    - **逻辑思路**：服务器内部错 → 功能未实现 → 网关收不到正常结果 → 服务过载 → 服务响应太慢
    - **归属**：**后端/服务器问题**（代码 bug、服务不可用、网络超时）

6. **常见状态码对比**
	- **401 vs 403**
		- 401：未认证（用户没登录/凭证错误）
		- 403：已认证，但权限不足（账号没权限/IP 被封）
	- **301 vs 302**
		- **301 Moved Permanently**（永久重定向）
			- 典型场景：网站换了新域名 / 新路径。
			- 例子：访问 `http://example.com` → 自动跳到 `https://example.com`。
			- 搜索引擎会记住新地址，下次直接用新地址。（搜索引擎会更新索引）
			- 后端写死的规则。
		- **302 Found**（临时重定向）
			- 典型场景：资源临时搬走了，或者未登录用户先跳到登录页。
			- 例子：访问 `/dashboard` 没登录 → 302 重定向到 `/login`。
			- 搜索引擎不会记住新地址，下次还是访问旧地址。（下次仍然访问旧地址）
			- 后端动态触发的规则
	- **4xx vs 5xx**
		- 4xx：**客户端错误**（请求问题：URL 错、没带 token、权限不足）
		- 5xx：**服务器错误**（服务端处理失败：代码 bug、网关问题、数据库挂了）
