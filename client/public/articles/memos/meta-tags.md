1. **字符编码**
    - charset → `<meta charset="UTF-8">`
2. **视口（移动端适配）**
    - viewport → `width=device-width, initial-scale=1.0`
3. **SEO（搜索优化）**
    - keywords → 页面关键词
    - description → 页面描述（搜索结果摘要）
4. **作者信息**
    - author → 页面作者
5. **浏览器兼容性**
    - http-equiv → `X-UA-Compatible=IE=edge`
6. **刷新与跳转**
    - refresh → 定时刷新 / 自动跳转
7. **社交媒体优化**
    - Open Graph（og:title, og:description, og:image, og:url）
