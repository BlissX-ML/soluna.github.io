1. **定义**
    - DNS（Domain Name System）是域名系统协议，用来**把域名解析为 IP 地址**。
    - 类似“网络电话本”，把人类好记的域名（[www.xxx.com](http://www.xxx.com/)）转换成机器能识别的 IP。
2. **工作过程（多层查询）**
    - 浏览器缓存 → 本地 hosts 文件 → 本地 DNS 缓存 → 本地 DNS 服务器 → 根域名服务器 → 顶级域名服务器（.com/.cn） → **权威域名服务器**。
    - 逐层查询，直到得到对应 IP 地址。
3. **什么是域名劫持？**
    - **定义**：在网络传输过程中**拦截域名解析请求**，并**返回错误的结果**。
    - **表现**：
        - 返回**假的 IP 地址** → 用户被引导到钓鱼网站。
        - 直接**不返回结果** → 域名无法解析，用户打不开网站。
    - 危害：导致用户访问假网址，或根本无法访问目标站点。
4. **面试速答**
    - DNS 是域名解析协议，把**域名翻译成 IP 地址**。
    - 解析过程是**逐层查询**（**缓存 → 本地 → 运营商 → 根域名 → 权威域名**）。
    - 常见风险是域名劫持，会返回假 IP 或直接无响应。
