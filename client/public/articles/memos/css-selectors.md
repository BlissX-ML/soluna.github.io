1. **常见选择器**
    1. **基础选择器**
        - ID 选择器：`#myid`
        - 类选择器：`.myclass`
        - 标签选择器：`div, h1, p`
        - 通配符选择器：
    2. **属性选择器**
        - `[attr]`：含有某属性
        - `[attr="value"]`：属性值等于 value
        - `[attr^="val"]`：属性值以 val 开头
        - `[attr$="val"]`：属性值以 val 结尾
        - `[attr*="val"]`：属性值包含 val
    3. **伪类选择器**
        - 动态伪类：`:hover`、`:active`、`:focus`
        - 结构伪类：`:first-child`、`:last-child`、`:nth-child(n)`、`:nth-of-type(n)`
    4. **伪元素选择器**
        - `::before`、`::after`、`::first-letter`、`::first-line`
    5. **组合选择器（关系选择器）**
        - 后代选择器：`li a`（li 内部的所有 a，包括嵌套多层 ）
        - 子选择器：`ul > li`（ul 的直接子 li，不包括孙子辈 ）
        - 相邻兄弟选择器：`h1 + p`（选择紧跟在 `h1` 后的第一个 `p` ）
        - 普通兄弟选择器：`h1 ~ p`（选择与 `h1` 同级、在它后面的所有 `p`）
2. **优先级计算规则**
    1. **优先级权重**
        - `!important`：最高优先级，覆盖一切（除非另一个也有 `!important`）
        - 内联样式：权值 `1000`（如 `<div style="...">`）
        - ID 选择器：权值 `0100`
        - 类 / 属性选择器 / 伪类：权值 `0010`
        - 标签选择器 / 伪元素：权值 `0001`
        - 通配符 、继承、关系选择器（`+ > ~`）：不增加权重
    2. **比较方式**
        - **important > 内联 > id > class/伪类/属性 > 标签/伪元素 > 通配**
        - **通配符、继承不增加权重，若权重相同则后写的生效。**
        - 如果权值相同 → 就近原则（后写的覆盖前写的）
