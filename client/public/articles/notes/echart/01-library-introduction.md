1. D3.js
    - Web 端评价最高的可视化库，灵活度极高。
    - 可定制度强，但入门难度偏高。
2. [ECharts](https://echarts.apache.org/zh/index.html)
    - 百度开源的 JavaScript 可视化库，本质是一个 JS 插件。
    - 性能好，PC 与移动端都能流畅运行。
    - 兼容主流浏览器。
    - 内置丰富图表类型，且支持高度定制。
