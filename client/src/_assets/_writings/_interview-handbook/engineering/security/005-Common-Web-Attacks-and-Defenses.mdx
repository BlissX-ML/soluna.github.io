> XSS = 黑客"写脚本"，让页面乱跳。 → 转义 + CSP
> CSRF = 黑客"骗你点链接"，偷偷替你操作。 → Token + SameSite
> SQL 注入 = 黑客"往数据库里塞垃圾"。 → 参数化查询
> DDoS = 黑客"发洪水"，把你服务器淹掉。 → CDN + 限流



1. **XSS（跨站脚本攻击）**
    - **原理**：向页面注入并执行恶意脚本，**用户访问时自动执行**，可窃取 cookie、session 等敏感信息
    - **防御方式**：
        - 输出时用 **`encodeURIComponent` 转义**
        - 避免使用 `innerHTML` 插入不可信内容
        - 对特殊符号、标签做转义处理

2. **CSRF（跨站请求伪造）**
    - **原理**：攻击者诱导用户**访问第三方页面**，诱导已登录用户在不知情的情况下发起对站点的请求
    - **防御方式**：
        - 添加**验证码**
        - 使用 **token 验证**机制（服务端生成并校验）

3. **SQL 注入**
    - **原理**：在输入中注入**恶意 SQL 语句**，后台数据库执行后造成数据泄露或破坏
    - **防御方式**：
        - 使用**预编译语句**（PreparedStatement）
        - 输入校验与过滤

4. **DDoS（分布式拒绝服务）**
    - **原理**：攻击者利用**大量请求造成资源过载**，使服务器无法正常服务
    - **防御方式**：
        - 限流（rate limiting）
		- 弹性扩容 / 负载均衡
        - 防火墙过滤异常流量（如禁止 ICMP 包）
        - 检查和关闭不必要的特权端口

5. **Web 攻击速记总结**
    - XSS（跨站脚本 → 注入恶意脚本） → 解决：转义输入 / 避免 innerHTML
    - CSRF（跨站请求伪造 → 第三方伪造请求） → 解决：验证码 / Token 校验
    - SQL 注入（恶意 SQL 拼接 → 操控数据库） → 解决：预编译 / 输入过滤
    - DDoS（分布式拒绝服务 → 大量请求超载） → 解决：限流 / 防火墙 / 关闭无用端口
