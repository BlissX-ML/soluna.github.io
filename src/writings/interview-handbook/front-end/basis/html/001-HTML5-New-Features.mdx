1. **语义化标签**

- 新增结构化标签：`<header>`, `<footer>`, `<section>`, `<article>`, `<nav>`, `<aside>` 等
- 优势：让 HTML 更有语义，利于 SEO 和可读性

2. **多媒体支持**
- 音视频标签：`<audio>`、`<video>`
- 提供原生播放控制，不再依赖 Flash

3. **图形与动画**
- Canvas：基于像素绘图，可用于图形渲染、游戏开发
- WebGL：基于 OpenGL ES 的 3D 绘图接口
- requestAnimationFrame：更高效的动画渲染方式

4. **API 功能扩展**
- 拖拽释放 API（Drag and Drop）
- History API：支持浏览器历史记录的管理（如单页应用的前进/后退）
- 地理位置 API（Geolocation）：获取用户位置信息
- WebSocket：提供浏览器和服务器之间的双向通信，适合实时应用（如聊天、推送）

5. **存储与缓存**
- Web Storage：
    - localStorage（持久化存储）
    - sessionStorage（会话存储）
- 还包括 IndexedDB、Application Cache（已逐渐废弃，改用 Service Worker）

6. **表单增强**
- 新增控件类型：
    - 日期时间：date、time、datetime-local、month、week
    - 输入校验：email、url、number、range、search、tel
- 提升表单交互体验与验证能力


## 知识扩展

#### 什么是Flash？
- 早期浏览器用 `<object>`、`<embed>` 来嵌入 Flash。但是HTML5 不支持 Flash，而是用原生多媒体标签和 API 替代。

#### Canvas画布怎么使用？
- 直接写标签 `<canvas id="cvs" width="300" height="200"></canvas>`
- 再用 JavaScript 获取上下文绘制
    ```javascript
    const canvas = document.getElementById('cvs')
    const ctx = canvas.getContext("2d");
    ctx.fillStyle = "red";
    ctx.fillRect(50, 50, 100, 100);
    ```

#### WebGL 和 OpenGL ES 都是什么？
- OpenGL ES 是一个跨平台的 3D 图形标准
- WebGL 是把 OpenGL ES 的功能移植到浏览器里，通过 Canvas + JavaScript 调用 GPU 绘制 3D 图形。
    - 简单理解：WebGL = 浏览器里的 3D 版 Canvas。
    - 实际开发较为复杂，所以需要使用 Three.js 这样的库来简化开发。

#### requestAnimationFrame 怎么实现代码？
- 用来替代 setInterval 做动画，更流畅节能。
    ```javascript
    function move() {
        box.style.left = (parseInt(box.style.left) || 0) + 2 + "px"; 
        requestAnimationFrame(move);   // 下一帧继续执行
    }
    requestAnimationFrame(move);
    ```

#### API 的功能要怎么实现？
- 拖拽 API
    ```html
    <div draggable="true" id="drag">拖拽</div>
    <div id="drop"></div>
    <script>
        drag.ondragstart = e => e.dataTransfer.setData("text", "Hello");
        drop.ondrop = e => { e.preventDefault(); drop.innerText = e.dataTransfer.getData("text"); }
        drop.ondragover = e => e.preventDefault();
    </script>
    ```

- History API
    ```javascript
    history.pushState({page:1}, "title1", "?page=1");
    history.back();    // 后退
    ```

- Geolocation API
    ```javascript
    navigator.geolocation.getCurrentPosition(pos => {
        console.log(pos.coords.latitude, pos.coords.longitude);
    });
    ```

- WebSocket
    ```javascript
    const ws = new WebSocket("ws://echo.websocket.org");
    ws.onopen = () => ws.send("Hello");
    ws.onmessage = e => console.log(e.data);
    ```

#### LocalStorage 和 SessionStorage 的区别
1. **相同点**：都是键值对存储，只能存字符串。

2. **不同点**：
    - localStorage：持久存储，关掉浏览器也不会消失。
    - sessionStorage：临时存储，关闭标签页就清空。

3. **常用方法**：`setItem`, `getItem`, `clearItem`, `clear`


#### 语义化优点
1. **有利于 SEO**
    - 搜索引擎会根据标签的语义来理解页面结构，比如 `<header>`、`<article>`、`<nav>`、`<footer>`，会被赋予不同权重。
    - 能帮助搜索引擎更准确地索引和排名。
2. **代码结构清晰，可读性更好**
    - 相比一堆 `<div>`，使用 `<section>`、`<aside>`、`<main>` 能让代码更直观。
    - 团队协作、后期维护都更方便。
3. **默认样式支持（有限）**
    - 一些语义化标签在浏览器里自带简单的默认样式。
    - 这些默认样式在“没有 CSS”时，可以保证基本的结构层级。
4. **更好地被辅助设备解析**
    - 屏幕阅读器、智能终端、语音助手等，可以根据语义化标签更好地朗读或渲染页面。
    - 提升网页的 **可访问性（Accessibility）**。
