1. 在 JS 中，数据类型分为 **基本类型 (Primitive)** 和 **引用类型 (Reference)**。

2. **原始类型 (Primitive)**：
    - `Number`、`String`、`Boolean`、`Undefined`、`Null`、`Symbol`、`BigInt`
    - 存储在 **栈内存**，不可再分，操作时是 **值的拷贝**。

3. **引用类型 (Reference)**：
    - `Object`（包括 Array、Function、RegExp正则、Date 等）。
    - 存储在 **堆内存**，变量存的是引用地址，操作时是 **地址的拷贝**（多个变量可能指向同一对象）。
