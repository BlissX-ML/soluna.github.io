titleCh: '数字签名是什么？'

> **签名 ≠ 加密**，它的目标不是保密，而是 **防篡改 + 身份认证**。

1. 数字签名主要用于 **证明消息的完整性和发送者身份**。

2. **流程**：
    - **发送方**：
        - **用哈希函数对消息做摘要**（比如 SHA256）
        - 用**发送方的私钥**加密摘要得到数字签名。
        - 把 **消息 + 签名** 一起发送出去
    - **接收方**：
        - 用相同的哈希函数对消息再做一次摘要。
        - 用 **发送方的公钥** 解密签名 → 得到发送方原本生成的摘要。
        - 比较本地算出的摘要和公钥解密得到的摘要：
            - 一致 → 消息没被篡改，确实来自私钥持有者。
            - 不一致 → 数据被动过或不是原始发送方。
