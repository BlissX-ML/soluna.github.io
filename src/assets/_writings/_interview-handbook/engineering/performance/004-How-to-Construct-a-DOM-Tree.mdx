titleCh: '如何构建 DOM Tree？'
tags: ['DNS', 'DOM Tree']
---

1. **转码：**二进制数据转为 HTML 字符串

2. **分词（Tokenizer）：**将字符串解析为 Token（**词法单元**，标签、属性、文本等）

3. **构建 Node：**根据 Token 生成 Node（DOM 节点对象，包含属性、父子/兄弟指针）

4. **生成 DOM Tree：**通过 Node 的关系拼接成完整 DOM 树

5. **总结：二进制数据 → 字符串 → Token → Node → DOM 树**
