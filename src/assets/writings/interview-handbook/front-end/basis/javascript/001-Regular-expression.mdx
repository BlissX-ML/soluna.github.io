1. **基本规则**
    - 用 `/.../` 包裹（JS 里写成 `/abc/`）
    - `.`：匹配任意一个字符（除了换行）
    - `\s`：匹配空白字符（空格、换行、制表符等）
    - **`\d`**：匹配数字，等价于 `[0-9]`
    - `\w`：匹配字母、数字、下划线，等价于 `[a-zA-Z0-9_]`
    - `^`：匹配开头
    - `$`：匹配结尾
    - `[]`：字符集，比如 `[abc]` 表示 a 或 b 或 c
        - `[.-]` = 匹配 “`.`” 或 “`-`”
    - `[^...]`：取反，比如 `[^0-9]` 表示非数字
    - `?=`：表示 **正向前瞻**，要求当前位置右边必须满足括号里的规则，但不消耗字符。
        - `(?=.*[A-Za-z])` → 要求字符串里至少有一个字母

2. **数量词**
    - **`*`**：出现 0 次或多次
        - `.*` → 任意字符出现 0 次或多次
    - **`+`**：出现 1 次或多次
    - **`?`**：出现 0 次或 1 次
    - `{n}`：出现 n 次
    - `{n,}`：至少出现 n 次
    - `{n,m}`：出现 n 到 m 次之间
    - 量词只作用于前面的“一个单位”

3. **常见应用**
    - **手机号**：`/^1[3-9]\d{9}$/`
    - **邮箱**：`/^[\w.-]+@[a-zA-Z0-9.-]+\.[a-zA-Z]{2,}$/`
        - `[\w.-]+`：至少一个“字母/数字/下划线/点/横杠”
        - `[a-zA-Z0-9.-]+`：域名部分，至少一个“字母/数字/点/横杠”
        - `\.` → 字面量的点（域名里的 `.`）
    - **身份证号(18位)**：`/^\d{17}[\dXx]$/`
    - **URL**：`/^https?:\/\/[^\s]+$/`
        - `//` 是正则的包裹符号，不是内容
        - `\/\/`匹配 `//`
            - 因为正则里 `\` 是转义符，所以要写两次 `\/` 来表示字面量的斜杠 `/`。
    - **IP 地址**：`/^(\d{1,3}\.){3}\d{1,3}$/`
    - **只含字母和数字**：`/^[a-zA-Z0-9]+$/`
    - **6 位数字验证码**：`/^\d{6}$/`
    - **密码(6-20位，必须包含字母和数字)**：`/^(?=.[A-Za-z])(?=.\d)[A-Za-z\d]{6,20}$/`
