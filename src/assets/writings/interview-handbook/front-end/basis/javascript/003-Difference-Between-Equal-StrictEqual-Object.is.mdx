---
titleEn: 'Difference Between ==, === and Object.is()'
titleCh: '==,  === 以及 Object.is() 之间的区别'
tags: ['JavaScript', 'Comparison', 'data type']
---

1. **`==`（宽松相等 / 抽象相等）**
    - 会进行 **类型转换** 后再比较
    - 例如：
        - `5 == "5"` → True（字符串转数字后再比）
        - `0 == false` → True
        - `null == undefined` → True
    - 特殊情况：
        - `+0 == -0` ✅ True
        - `NaN == NaN` ❌ False

2. **`===`（严格相等）**
    - 不会进行类型转换，必须 **类型和值都相同**
    - 例如：
        - `5 === "5"` → False（类型不同）
        - `0 === false` → False
        - `null === undefined` → False
    - 特殊情况：
        - `+0 === -0` ✅ True
        - `NaN === NaN` ❌ False

3. **`Object.is()`（同值相等）**
    - 比较规则接近 `===`，但有两个区别：
        - `+0` 和 `0` → False
        - `NaN` 和 `NaN` → True
    - 特点：
        - `Object.is(+0, -0)` ❌ False
        - `Object.is(NaN, NaN)` ✅ true
