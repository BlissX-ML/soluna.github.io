1. **是否修改原数组**
    - **修改原数组**
        - `push()`：尾部添加
        - `pop()`：尾部删除
        - `shift()`：头部删除
        - `unshift()`：头部添加
        - `splice(start, deleteCount, ...)`：增删改
        - `fill(value, start?, end?)`：填充
        - `sort(compareFn)`：排序
        - `reverse()`：反转
        - `copyWithin(target, start?, end?)`：数组内复制
    - **不修改原数组**
        - `slice(start, end)`：截取
        - `concat()`：合并
        - `filter(fn)`：过滤
        - `map(fn)`：映射
        - `flat(depth?)`：扁平化
        - `flatMap(fn)`：先 map 再扁平化
        - `find(fn)`：找到第一个匹配值
        - `findIndex(fn)`：找到第一个匹配索引
        - `every(fn)`：是否所有元素满足条件
        - `some(fn)`：是否有元素满足条件
        - `includes(value)`：是否包含某值
        - `indexOf(value)`：查找首次索引
        - `lastIndexOf(value)`：查找最后索引
        - `forEach(fn)`：遍历（无返回值）
        - `entries()` / `keys()` / `values()`：迭代器
        - `toString()` / `toLocaleString()`：转字符串

2. **返回值类型**
    - **返回新数组**
        - `slice()`、`concat()`、`filter()`、`map()`、`flat()`、`flatMap()`
    - **返回单个值**
        - `pop()`（被删除的值）
        - `shift()`（被删除的值）
        - `find()`（第一个匹配值）
        - `findIndex()`（第一个匹配索引）
        - `indexOf()` / `lastIndexOf()`（索引）
        - `every()` / `some()`（布尔值）
        - `includes()`（布尔值）
    - **返回数组长度**
        - `push()`、`unshift()`
    - **无返回值（undefined）**
        - `forEach()`
    - **返回迭代器对象**
        - `entries()`、`keys()`、`values()`
    - **返回字符串**
        - `join()`、`toString()`、`toLocaleString()`

3. **功能分类**
    - **增删改**：`push`、`pop`、`shift`、`unshift`、`splice`、`fill`、`copyWithin`
    - **取值 / 查找**：`slice`、`find`、`findIndex`、`indexOf`、`lastIndexOf`、`includes`
    - **合并 / 扁平化**：`concat`、`flat`、`flatMap`
    - **排序 / 反转**：`sort`、`reverse`
    - **遍历**：`forEach`、`map`、`filter`、`every`、`some`
    - **迭代器**：`entries`、`keys`、`values`
    - **转字符串**：`join`、`toString`、`toLocaleString`
