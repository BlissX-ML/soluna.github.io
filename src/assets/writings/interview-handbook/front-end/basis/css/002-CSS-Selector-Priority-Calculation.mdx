1. **优先级权重**
    - `!important`：最高优先级，覆盖一切（除非另一个也有 `!important`）
    - 内联样式：权值 `1000`（如 `<div style="...">`）
    - ID 选择器：权值 `0100`
    - 类 / 属性选择器 / 伪类：权值 `0010`
    - 标签选择器 / 伪元素：权值 `0001`
    - 通配符 、继承、关系选择器（`+ > ~`）：不增加权重

2. **比较方式**
    - **`!important` > 内联样式 > ID > 类/属性/伪类 > 标签/伪元素。通配符、继承不增加权重，若权重相同则后写的生效。**
    - 如果权值相同 → 就近原则（后写的覆盖前写的）
