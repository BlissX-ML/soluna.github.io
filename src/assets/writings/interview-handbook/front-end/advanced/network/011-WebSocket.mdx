1. **实现原理**
    - 建立在 **TCP 协议** 之上的新协议
    - 握手阶段使用 **HTTP 协议**（为了兼容），握手成功后改用 TCP 通道传输
    - 实现 **客户端与服务端双向通信**（一次连接，多次通信）
    - 数据以 **frame（帧）** 形式传输
        - 支持分片传输大数据
        - 可边生成边发送，提高效率

2. **优点（双向通信，高效轻量化）**
    - 一次握手即可建立持久的双向通信通道，轻量高效、突破同源限制，适合实时场景。

3. **缺点（后端压力 + 兼容差 + 网络要求高）**
    - 需要维持长连接，服务端要管理大量连接；同时依赖网络环境稳定性
    - 兼容性问题：现在现代主流浏览器都支持（所以这条基本可以当成历史问题）

4. **适用场景**
    - 即时通讯（IM、聊天室）
    - 实时更新（股票、体育比分、游戏状态）
    - 实时协作（文档协作、在线白板）
