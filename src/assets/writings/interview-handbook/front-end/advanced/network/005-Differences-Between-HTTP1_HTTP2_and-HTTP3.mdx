---
titleEn: 'Differences Between HTTP/1, HTTP/2, and HTTP/3'
titleCh: 'HTTP1, HTTP2, HTTP3 的区别'
tags: ['HTTP']
---


1. **HTTP/1.0**
    - **特点**：浏览器与服务器**只保持短暂连接**。
    - **工作方式**：每次请求都要新建一个 TCP 连接 → **请求结束就断开**。
    - **具体实现**：同HTTP/1.1。
    - **缺点**：频繁建连和断连，开销很大。
    - **举例**：像你和朋友发短信，每说一句话都要挂掉电话，再重新拨号。

2. **HTTP/1.1**
    - **特点**：引入了**持久连接（Keep-Alive）**，一个 TCP 连接可以发多个请求。
    - **工作方式**：可以同时传递很多请求，但**同一个连接里的请求必须排队顺序处理**（队头阻塞）。
    - **具体实现**：**基于 TCP**，把**文本格式**的请求和响应写在 TCP 上。
    - **新增功能**：更多请求方法（PUT、DELETE）、更多请求头和响应头。
    - **举例**：和朋友开了一个电话会议，可以连续说多件事，但必须**一个一个说完**。

3. **HTTP/2.0**
    - **特点**：采用**二进制格式**（不是文本），计算机更容易理解。
    - **具体实现**：**基于 TCP**，但在应用层里改成二进制分帧，**多路复用、头部压缩**。
    - **多路复用**：**一个连接里能同时传多个请求**，互不阻塞。
    - **报头压缩**：减少重复信息，提高效率。
    - **服务器推送**：服务器能主动把可能需要的资源发给浏览器。
    - **举例**：你和朋友用微信语音，能同时聊多件事（并行），而且对方还能主动发你需要的文件。

4. **HTTP/3.0**
    - 特点：基于 **UDP + QUIC（运行在 UDP 上的 HTTP 专属 TCP++）**。
    - 优势：速度快、可靠性高，不受 TCP 队头阻塞影响。
    - 举例：像用微信视频，既快又稳定，即使网络不太好也能保证体验。
