1. **非对称加密不需要自己手写底层代码**（手写极其复杂，容易有安全漏洞）。
    - 实际项目中用 **现成的库/插件** 就可以（例如 OpenSSL、CryptoJS、Java 的 javax.crypto 等）。
    - **前端/后端都能用**：
        - 前端：通常用 **`crypto-js`**（加密少量敏感数据，比如本地存储加密、简单签名）。
        - 后端：用 OpenSSL、Node.js crypto 模块、Java/Python 等标准库，负责真正的安全通信。

2. 对称加密**同样不需要手写，直接调用库**。
    - 前端 JS 里常用：
        - **`crypto.subtle`**（Web Crypto API）
        - **`node:crypto`** 模块（Node.js）
    - 后端里（常见语言）：
        - Java → `java.security`
        - Python → `pycryptodome`
        - OpenSSL → 命令行/库调用
