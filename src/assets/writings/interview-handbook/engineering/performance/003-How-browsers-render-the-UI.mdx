1. **浏览器如何渲染UI？**
    - **解析 HTML：**构建 **DOM Tree**
    - **解析 CSS：**构建 **CSSOM Tree（Style Rules）**
    - **合并：**DOM + CSSOM → **Render Tree**（只包含可见节点）
    - **布局（Layout）：**计算各节点的大小和位置（盒模型尺寸 + 坐标）
    - **绘制（Paint）：**将 Render Tree 转换成绘制指令（颜色、文字、边框等）
    - **合成（Composite）：**多层图层交给 GPU，最终渲染到屏幕

2. **展示引擎（Rendering Engine）** 负责 UI 渲染流程
