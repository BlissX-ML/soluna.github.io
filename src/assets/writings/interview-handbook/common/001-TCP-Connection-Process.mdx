1. **三次握手和四次挥手是 TCP 连接建立与断开 的过程。**

2. **三次握手（建立连接）**
    - **客户端 → 服务器**：请求建立连接。（SYN=1, synchronize）
    - **服务器 → 客户端**：同意并确认收到。（SYN=1, ACK=1）
    - **客户端 → 服务器**：收到！（ACK=1, acknowledgement）

3. **四次挥手（断开连接）**
    - **客户端 → 服务器**：我要断开。（FIN=1, finish）
    - **服务器 → 客户端**：收到。（ACK=1）
    - **服务器 → 客户端**：我也要断开。（FIN=1）
    - **客户端 → 服务器**：确认。（ACK=1）
