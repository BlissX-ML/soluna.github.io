---
titleEn: 'How to Resolve Domain Hijacking'
titleCh: '如何解决域名劫持？'
tags: ['DNS', 'DNS Hijacking']
---

1. **问题**：劫持会返回假 IP，或者直接不返回 → 访问不到目标网站。

2. **常见应对方式**：
    - 使用 **HTTPS + 证书校验**（即使 DNS 被劫持，假网站证书校验不过）。
    - 使用 **可信 DNS 服务**（如 8.8.8.8 Google DNS，1.1.1.1 Cloudflare）。
    - 开启 **DNS over HTTPS（DoH）/ DNS over TLS（DoT）**，把 DNS **请求加密**。
    - 使用 **VPN** 绕过被劫持的网络环境。

3. 面试速答：
    - **域名劫持常见的防护手段是用 HTTPS 校验证书，或者使用 DoH/DoT 让 DNS 查询加密。**
