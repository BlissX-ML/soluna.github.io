titleEn: 'How is DNS resolution achieved?'
titleCh: 'DNS 解析是怎么实现的'

---


1. **基本原理**：DNS 是一个分布式的树状系统，通过**逐级查询**把域名转换成 IP 地址。

2. **解析过程**（简化版）：
    - 先查本地缓存（浏览器、本机 hosts 文件、本地 DNS 缓存）。
    - 如果没有，再问运营商的 DNS 服务器。
    - 如果运营商也没有 → 它会递归去查：
        - **根域名服务器** → **顶级域名**服务器（.com / .cn） → **权威 DNS** 服务器。
    - 最终返回 IP 地址给客户端。

3. **面试速答**：
    - **DNS 解析就是从本地缓存开始，逐层向上查到权威服务器，把域名解析成 IP 地址。**
    - 只要域名有效，最终一定能解析到 IP；如果解析不到，大概率是域名配置有问题
    - 实际开发中不会手写 DNS 解析，操作系统和浏览器都会做，可以用 nslookup/dig 这类工具调试。
